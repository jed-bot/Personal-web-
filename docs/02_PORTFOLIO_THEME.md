# Portfolio Theme

> The theme is the emotional foundation of the entire portfolio. It defines how the site **feels** before it defines how it looks.

---

## Philosophy

The portfolio should feel like a premium digital product. Every decision — from color to copy to animation — must reinforce **trust, quality, and professionalism**.

The design should never feel:

- Generic
- Crowded
- Overdesigned
- Colorful everywhere
- Template-looking

---

## Personality

| Trait | Expression |
|-------|------------|
| Calm | Generous whitespace, soft transitions |
| Professional | Clean hierarchy, restrained palette |
| Focused | One clear CTA per section |
| Creative | Subtle micro-interactions, unique layouts |
| Curious | Case studies that show process |
| Approachable | Warm accent, readable type |
| Intelligent | Structured content, logical flow |

The design should avoid looking flashy. Create confidence through simplicity.

See [[04_UI_GUIDELINES]] for how personality translates to UI decisions.

---

## Visual Identity Keywords

- Minimal · Premium · Elegant · Modern
- Professional · Technical · Clean
- Soft · Confident · Timeless

---

## Overall Feeling

The first impression should communicate:

1. "I build modern software."
2. "I care about quality."
3. "I understand design."
4. "I build products, not just code."

Visitors should immediately feel confident hiring.

See [[08_CONTENT_STRATEGY]] for messaging that reinforces this feeling.

---

## Emotional Goal

> The portfolio should leave a memorable impression without relying on excessive animations or visual effects.

The emotional arc:

1. **First impression** — Premium, confident, trustworthy
2. **Browsing** — Engaged by case studies and animations
3. **Conversion** — Clear path to contact/hire

See [[07_CASE_STUDY_STRUCTURE]] for the narrative arc and [[06_ANIMATION_GUIDE]] for motion design.

## Design Inspiration

| Site | What to study |
|------|---------------|
| Apple | Typography, whitespace, product presentation |
| Linear | Dark mode depth, glassmorphism, motion |
| Vercel | Minimalism, developer-focused design |
| Framer | Animation patterns, interactive demos |
| Raycast | Speed-focused UX, clean layout |
| Notion | Information hierarchy, clean grids |
| Stripe | Gradient usage, professional polish |

**Do not copy.** Use as reference for spacing, typography, interaction, and visual hierarchy.

---

## Dark Mode First

The portfolio is designed primarily for dark mode:

- Dark mode should feel **luxurious**, not simply black
- Use multiple background shades to create depth
- Avoid flat backgrounds
- Reference [[03_DESIGN_SYSTEM]] for the color system

---

## Lighting

- Subtle radial lighting
- Soft green glow
- Blurred circles
- Very subtle gradients
- No aggressive neon
- Lighting should guide attention

See [[04_UI_GUIDELINES]] for implementation details and [[05_COMPONENT_LIBRARY]] for component-level lighting.

---

## Background

Multiple background layers:

1. Dark gradient base
2. Soft blur overlay
3. Floating light orbs
4. Tiny particles
5. Noise texture (very subtle)

Background should never distract from the content.
