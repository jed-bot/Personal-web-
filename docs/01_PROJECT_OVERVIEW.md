# Project Overview

> **Version:** 1.0
> **Type:** Personal Portfolio Website
> **Role:** Full Stack Developer / UI-UX-Focused Engineer / AI Application Developer

---

## Purpose

This project is a personal portfolio website that should feel like a **premium digital product** rather than a traditional résumé. The experience must communicate confidence, craftsmanship, simplicity, and professionalism.

---

## Core Principles

- Every section should feel intentional
- Avoid unnecessary decoration
- Every visual element must reinforce trust
- Look like it belongs to an experienced software engineer who understands product design and UX

## Design Inspiration

Use these as **reference only** — never copy:

- Apple, Linear, Vercel, Framer, Raycast, Notion, Stripe

Study them for spacing, typography, interaction patterns, and visual hierarchy.

See [[02_PORTFOLIO_THEME]] for full theme details and [[04_UI_GUIDELINES]] for layout implementation.

---

## Emotional Goal

Visitors should immediately think:

> "This developer understands modern software."
> "This feels premium."
> "I trust this person."
> "I want this quality for my own product."

The portfolio is not a résumé. It is a **product experience** that showcases ability.

---

## Design Principle

> **Less, but better.**

- Every component must have a purpose
- Every animation must improve the experience
- Every section should contribute to the story

See [[06_ANIMATION_GUIDE]] for motion rules and [[11_DEVELOPMENT_RULES]] for technical constraints.
